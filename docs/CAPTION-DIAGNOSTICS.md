# Caption request diagnostics（字幕请求诊断）

本补丁只诊断，不修复字幕、不自动重试、不修改Cookie、URL、语言、请求头或字幕正文。它与HansFix、Remember subtitle language是同一源的三个独立补丁。

## 手机构建

1. 刷新原 HansFix dev 源并开启预发布。
2. 选择未打补丁的 YouTube 原 APK。本次本地验证目标为21.13.164（1561063732），官方补丁1.42.0，Patcher1.12.0。
3. 在同一次专家模式改包中选择官方 **Captions** 与本源 **Caption request diagnostics**。原来的HansFix和Remember subtitle language按需保留。
4. 新诊断补丁默认不勾选；只需要诊断时选中。生成后由Morphe在手机本地签名安装，不上传APK或签名材料。
5. 更新使用原有签名，不卸载、不清除YouTube数据。手机安装和运行仍须用户验收。

## 如何取得一份有用的报告

- 打开YouTube设置 → Morphe → **字幕诊断（Caption diagnostics）**（Morphe设置根页，三种图标样式均通过官方add-on偏好协议合并）。
- 点 **开始记录**。默认关闭，每次进程重启都不会自行开启；新开始替换旧报告。
- 关闭弹窗返回播放，重新打开一个视频，以便捕获新请求。
- 先选原语言字幕，再手动选择一个出现空白的自动翻译语言。仅做少量切换，不用连续尝试大量语言。
- 回到同一诊断入口，先 **停止记录**，再 **查看 / 刷新报告** 或 **复制报告到系统剪贴板**。
- 把报告粘贴给分析者，并补充这次哪一步正常/空白，以及当时用的是流伪装还是外置PotHelper。无需发送Cookie、PoToken原值或账号资料。
- **清空并停止**会删除应用内诊断记录；此前主动复制到系统剪贴板或粘贴到其他地方的副本不会自动删除。

最多保留80条请求，按进程单调时钟约15分钟自动停止（不是包含设备深度休眠的严格现实时间保证）。只在内存保存，进程退出/被系统回收会丢失；应用暂时退到后台不一定退出进程。复制前不要强制停止YouTube。

## 能说明什么

- `/api/timedtext`请求是否经过已绑定的Cronet入口；原轨与tlang翻译参数的有限分类。
- HTTP状态、Content-Type有限分类、整数Retry-After、终止状态。
- 已观察到的Cookie/UA构建器调用次数和有限分类；**不证明网络上发送成功，更不证明Cookie有效**。
- URL是否出现pot参数；**不证明token有效，也不证明其他位置没有携带token**。
- 使用读取前后ByteBuffer position差值计算的已观察字节量。缺基线、异常和重定向明确标记不完整。

`terminal=success`是Cronet传输结束，不是字幕翻译成功。HTTP 429即使传输成功仍然是服务端拒绝。

## 不能说明什么

- 不解析或保存字幕正文，因此不能证明内容是合法字幕、不统计cue数、不证明渲染正常。
- 零读取不能独立证明响应为空；没有记录也不能独立证明客户端没有发送请求（可能录制时机或其他网络路径）。
- 不收集视频ID、标题、完整URL、Cookie/token值、账号、异常文本。报告不会自动关联视频，请用户说明手动测试顺序。
- 不探测PotHelper内部状态，不检查token加密有效性，不重新发起网络请求。
- 重定向目标不采集，重定向后的响应/读取不做字幕归因。
- 当前只支持匹配的原生Cronet路径，未来版本通过结构检查不等于手机运行已验收。

## 工程边界

- 正式Morphe `bytecodePatch`，default=false，Google包名/签名检查，无跨bundle Kotlin对象依赖。
- 共享自有extension只合并一次；使用官方1.42.0的`morphe_addon_prefs.xml`声明协议，不复制官方设置实现。
- 在finalize按当前字节码重新定位请求构建、其回调类、其InputStream reader及header writer。关键入口不唯一则失败；不硬编码YouTube混淆类名。
- header桥只观察后原样调用原addHeader一次，保留返回值和原异常；读请求原调用保留；回调只追加无副作用诊断入口。
- 所有观察入口吞掉自身异常，不输出原异常；内存有界、对象弱引用、按identity比较，不调用宿主对象toString/equals/hashCode。
- 只采集白名单短语言/格式/客户端分类。非预期、重复或未知参数标记unknown/other/ambiguous，不原样输出。
