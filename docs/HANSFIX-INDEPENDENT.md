# HansFix 独立运行与字幕菜单统一显示

## 可行性与原因

2026-09-11 用户实测：关闭官方字幕 Cookie 后，仍可显示繁体自动翻译，只是没有变成简体。旧版 HansFix 将自己的启用状态绑定到了官方 Cookie 开关，因此这是本插件的软件限制，不是该实测场景下的字幕下载失败。

本次移除该依赖，不新增 Cookie、账号或翻译服务。独立定位原生 Cronet 字幕请求方法，只将 YouTube timedtext 的 `tlang=zh-Hant` 改为 `zh-Hans`；其他参数保持原样。安装 HansFix 后始终生效，仅安装字幕记忆补丁时不会意外开启 HansFix。官方 Captions 存在时保留其 Cookie 和 User-Agent 处理；不存在时也可应用 HansFix。

## 菜单方案

CC 长按菜单与设置中的字幕菜单使用不同显示路径。除了原来的列表行与摘要，还处理本地字幕描述消息的文字生成，以及读取轨道名称的其他界面入口。

设置菜单的回调会比较名称、VSS ID 和语言码。名称生成与对应名称比较必须使用同一映射，才能避免文字改名后选项无法匹配。仅调整显示文字表达；轨道字段、语言码、VSS ID、字幕 URL、轨道 `toString/hashCode` 及其他匹配条件均保留。

只改会被映射为简体的繁体自动翻译选项，不全局替换“繁体”文字，也不将真正的原生繁体字幕错误标成简体。旧列表同时存在简体入口时仍保留“兼容入口”的区分。

## 使用与验收

继续使用同一个 dev 源，刷新预发布后，以原始 YouTube APK 同次选择官方补丁和 HansFix；字幕记忆补丁可一起选择。无需修改原来的源地址，无精确版本号硬限制。

独立于官方扩展的构建承诺仅针对 HansFix。现有字幕记忆补丁仍明确要求同次选择官方 Captions，其官方组合已经纳入验证。

验证目标为 YouTube 21.13.164、官方补丁 1.42.0、Patcher 1.12.0。快速检查、组合构建和输出检查结果单独记录，不能替代手机验收。

手机只需检查：

1. 关闭官方字幕 Cookie 并按设置要求重启；选择简体自动翻译，确认实际字幕为简体。
2. 检查长按 CC、设置→字幕→自动翻译，以及设置首页的已选字幕摘要；菜单应显示简体，且能够正确选中。
3. 开启官方字幕 Cookie 并重启，确认上述功能仍正常；切换下一视频确认字幕记忆继续有效。

本插件不解决原本就无法下载字幕的服务器限制，也无法为无字幕视频生成字幕。特殊服务端菜单或未来结构变化仍以实际结构检测及手机反馈为准。
